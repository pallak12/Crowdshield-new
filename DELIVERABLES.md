## Scope Statement

The current implementation is a functional competition prototype, not a production emergency-response system.

The current risk/recommendation layer is based on simulated metrics, thresholds and scenario rules. A production version should add a validated ML risk model trained on representative crowd-safety data.

## Suggested Demo Flow

1. Start the dashboard.
2. Show normal crowd movement.
3. Trigger a congestion/blockage scenario.
4. Show density/risk indicators changing.
5. Show the recommendation generated by the system.
6. Use a voice command to perform an intervention.
7. Show the crowd response in the digital twin.
8. Submit an incident report.
9. Show the resulting operational log/action.
10. Explain privacy and human oversight.
